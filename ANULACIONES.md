# Anular productos

Entra como caja o administrador, abre una mesa y busca **Ya enviado a esta mesa → Anular**. Indica el motivo y confirma. Los mozos pueden consultar las anulaciones, pero no realizarlas.

Esta versión anula la línea completa: si contiene tres unidades, anula las tres. No elimina el registro original. Conserva cantidad, precio, estado de preparación, responsable, fecha y motivo. El historial muestra el producto como anulado; el total, el cobro y las nuevas precuentas lo excluyen. Cocina deja de ofrecer acciones de preparación sobre ese producto.

Se genera un aviso **ANULACIÓN** para la ticketera del área correspondiente. Revisa su resultado en Tickets. Si falta impresora, el aviso permanece bloqueado y debe comunicarse al personal. El envío por red no confirma que salió papel ni que cocina recibió el aviso. La comanda original se conserva, junto con el aviso posterior de anulación.

Las precuentas pendientes sin envío se invalidan al anular. Si una precuenta está en envío o tiene resultado incierto, primero resuelve ese ticket. No se permite reimprimir una precuenta anterior a la anulación: genera una nueva. Si entregaste papel al cliente, reemplázalo por la precuenta actualizada.

No se pueden anular productos de cuentas cobradas. Las devoluciones y anulaciones parciales quedan para una etapa posterior. Si anulas todo el consumo, puedes cerrar la cuenta con total cero desde Caja, teniendo un turno abierto.

Reinicia el servidor y recarga el navegador para aplicar la actualización. Se añaden campos al iniciar sin eliminar los pedidos existentes. Interfaz compilada; pruebas funcionales a cargo del propietario.
